# 复盘报告模板与标注规范（ashare-daily-review）

本文件定义九段式复盘的每个段落该写什么、怎么标注，以及行动建议的三要素格式。
SKILL.md 第 4 节规定顺序，此处给逐段"必含字段 + 标注示例"。

---

## 全局标注规则（贯穿全文）

每一条实质陈述前打标签：
- `【事实】`：工具返回或可核验公开数据/公告原文。例：`【事实】涨停 84 只（data_changedist）。`
- `【推断】`：基于事实的推导，附依据。例：`【推断】成交环比 -432 亿且普涨 → 缩量反弹（依据：changedist 量价结构）。`
- `【假设·待验证】`：对次日/因果的猜测，必附验证条件。例：`【假设·待验证】医药主线延续；验证：明日医药出现≥2只2连板。`（验证信号须可观察、可证伪）

消息归因段每条结尾追加因果标记：`[因果:已验证]`（price action 确认）、`[因果:未验证]`（仅消息、盘面未确认）、`[因果:未知]`。

## 0. 全景速览仪表盘（报告顶部，unnumbered）

置于九段式之前的一屏摘要，Markdown 表格 + 一行定性结论。示例：

| 维度 | 当日表现 |
|---|---|
| 指数 | 上证 +0.24% / 深成 +0.59% / 创业板 +0.64% / 科创50 -0.87% |
| 个股 | 上涨 4096 / 下跌 1347（涨占 73%） |
| 成交额 | 约 2.079 万亿（环比 -431 亿，缩量） |
| 涨跌停 | 涨停 84 / 跌停 13 |
| 核心资产 | 医药(创新药+6.46%)、贵金属(+5.50%) 领涨；科创50 逆势 |
| 资金面 | 主力净流入医药+黄金；机构于高位医药分歧 |
| 外围 | 美股盘中(纳指 -0.66%, 截至 22:00) / 港股恒生 +0.80% / 黄金 4545.4 |

> 定性：昨日冰点后的**缩量修复性反弹**，广度强但量能未跟进、连板晋级弱。

## 1. 市场状态
必含：
- 主要指数涨跌幅（**精确值来自 `data_quote`，codes=sh000001,sz399001,sz399006,sh000688,bj899050**；报点位+涨跌幅，如"上证指数收报 3903.72 点，涨 0.24%"）。
- 成交额 + 环比（放大/缩小）。
- 涨跌家数、涨停/跌停数。
- 量价定性一句话（普涨/分化/退潮/冰点/修复）。
- **外围市场（必含，代码与字段见 `data_sources.md` "外围市场"段）**：
  - 美股三大指数/ETF（`usIXIC`/`usDJI`/`usSPY`）：**当日盘中（截至复盘时刻 HH:MM，未收盘）**，报点位+涨跌幅。
  - 港股恒生（`hkHSI`）：**当日收盘**。
  - 外盘期货（`fuGC`黄金/`fuCL`原油/`fuHG`铜）：报价格+涨跌幅，标交易时段。
  - 汇率（美元指数/离岸人民币）：`data_forex` 实测可能无价位 → 标【未获取】，不编造。
  - 一句话外围定性（外围偏强/偏弱/中性，对次日 A 股风险偏好的指引方向）。
示例（外围段，接在市场状态后）：
> 【事实】美股盘中（截至 22:00，未收盘）：纳指 usIXIC -0.66%、道指 usDJI -0.66%、标普代表 usSPY -0.31%（data_quote）。
> 【事实】港股恒生指数当日收盘 +0.80%（data_quote hkHSI）。
> 【事实】COMEX 黄金 fuGC 4545.4（+0.3%），原油 fuCL、【铜】fuHG【视实返】（data_futures）。
> 【事实】美元指数/离岸人民币【未获取】（data_forex 仅返品种列表）。
> 【推断】美股盘中偏弱但港股收涨、黄金走强，外围对 A 股贵金属/医药避险逻辑仍有支撑，对科技股指引偏中性。
示例：
> 【事实】上证指数收报 3903.72 点（+0.24%），深证成指 13972.78 点（+0.59%），创业板指 3495.59 点（+0.64%），科创50 1652.97 点（-0.87%），北证50 1081.58 点（-0.06%）（data_quote）。
> 【事实】上涨 4096 / 下跌 1347，涨停 84 / 跌停 13（data_changedist）。
> 【事实】成交额约 2.079 万亿，环比 -431 亿（data_changedist）。
> 【推断】广度显著修复但量能环比收窄，判定为缩量修复性反弹（依据：changedist 量价结构 + 8-19→8-20 反转）。

## 2. 资金结构
必含：板块强弱（data_sector sw1 / data_hot board 涨跌幅）、主线资金流向（data_fund_flow 对核心个股验证净流入/流出）、大小盘/风格（market_overview rotation）。
要求：用资金流数据支撑"资金去哪了"，不空谈。
**资金轮动路径（强制 · 资金迁徙图 + 四维度资金表）**：先以迁徙图概括"谁流出 → 谁流入 → 驱动 → 本质"，再用四维度表把 北向/主力/游资/融资盘 各自方向落到证据。示例：

│ 航天装备 -5.66%（高位补跌）  │ 贵金属 +5.50%（避险）         │

## 3. 主线题材
必含：最强 1–3 条主线（带涨跌幅）、领涨代表、题材股单平均涨幅（data_stocklist avgChangePct）。
示例：`【事实】创新药概念股单 avg +6.46%、月累 +17.52%（data_stocklist）→ 当日最强主线。`

## 4. 消息归因（交叉验证矩阵）
用 Markdown 表格替代逐条罗列，强制"理论是否落地盘面"。列定义：
- **新闻事件**：来源 + 时间（data_hot news / data_news / data_notice / data_calendar / data_macro）。
- **理论传导**：该消息按常识应影响的板块与方向（偏多/偏空）。
- **实际盘面**：该板块/个股当日真实表现（来自 data_sector / data_quote / data_hot）。
- **匹配度**：`[已验证]`（price action 确认）/ `[未验证]`（仅消息、盘面未确认）/ `[背离]`（实际与理论相反）。
- **背离原因（推断）**：若背离，写清其他驱动（资金/技术/情绪/其他消息），标注 `【推断】`。

矩阵示例：
| 新闻事件 | 理论传导 | 实际盘面 | 匹配度 | 背离原因（推断） |
|---|---|---|---|---|
| mRNA 突破+创新药两大利好(证券时报) | 医药 偏多 | 创新药 +6.46%、20cm 涨停潮 | [已验证] | — |
| 晶圆代工涨价15%(证券时报) | 半导体 偏多 | 半导体 -0.36% | [未验证] | 利好兑现/资金分歧【推断】 |
| 沪八条 城市更新(上观) | 地产 偏多 | 房地产开发 +1.11% | [已验证] | — |
| 商务部回应关税摩擦(新华社) | 出口链 偏空 | A股未显著反应 | [背离] | 外围噪音，内需主导【推断】 |

> 严禁"出消息=涨/跌"直推；凡未经验证的消息不得作为行情原因。

## 5. 情绪周期
必含：
- 涨跌停板数据（见 §1）。
- 龙虎榜（data_lhb）：机构(jg)净买/净卖居前、游资(yyb)核心席位、北向(hgt/sgt)方向、合力/分歧信号。
- **连板雁阵图**（图文，见下方规范）。

### 雁阵图规范（连板高度分布表 + 文本阶梯图，真实数据，左对齐极简）
**用 `tdx_screener` 取真实连板梯队**（tdx-connector 已连接），禁止估算层级数量：
- `message="连板"`：全部连板清单（含"连续涨停天数/几天几板/短线主题"）。
- `message="3连板"/"4连板"/"5连板"`：逐级定位最高板与各级数量。
- 首板广度 = 涨停总数（data_changedist）− 连板总数；代表取自 data_hot(stock)。
- 若 tdx 不可达：标注【未获取】，仅列可核验的涨停总数与昨日涨停板块涨跌幅，**不得编造层级**。

**第一步：连板高度分布表（真实数量）**
| 空间高度(连板天数) | 数量 | 代表 |
|---|---|---|
| 最高板(如 4 板) | 1 | 金健米业（粮食/乡村振兴，换手板） |
| 3 板 | 0 | 断层 |
| 2 板 | 3 | 志邦家居/速达股份/汉森制药 |
| 首板（蜂群） | ~80 | 沃森/智飞/太辰光(20cm 医药群) |

**第二步：文本阶梯图（真实锚定 + 断层诊断）**
```
连板雁阵图（真实梯队 · tdx_screener）
┌────────────────────────────────────────────────────┐
│ 空间高度(连板) │ 数量 │ 代表 / 板型                  │
├────────────────────────────────────────────────────┤
│ 4板(最高标)    │ 1   │ 金健米业(粮食线,换手板,开16次)│
│ 3板            │ 0   │ 断层：4板直降2板              │
│ 2板            │ 3   │ 志邦家居/速达股份/汉森制药    │
│ 首板(蜂群)     │ ~80 │ 沃森/智飞/太辰光(20cm医药群)  │

头雁(高度锚)：金健米业 4板 —— 粮食/乡村振兴线，非医药
断层诊断：缺3板；高度标与医药首板蜂群分属不同题材 → 主线(height)与广度(breadth)错配
明日关键：金健米业能否封5板定高度；汉森制药(医药2板)能否带医药晋级
```
- 标注真实来源（tdx_screener）；不依赖 HTML/SVG。

## 10. Markdown 报告交付规范

- 标准 `.md` 文件，九个 `##` 二级标题分段，纯文本（可二次编辑、归档、转 HTML/PDF）。
- 顶部：`# 标题 + 日期`，副行注明数据来源与免责提示。
- 三类标签以行首 `【事实】`/`【推断】`/`【假设·待验证】` 标注；消息归因每条末尾 `[因果:已验证/未验证/未知]`。
- 第 5 段情绪周期内嵌 Markdown 雁阵图（见上）。
- 第 7/8 段预案用表格或"触发/失效/仓位上限"三行格式呈现。
- 末尾固定免责声明。

## 6. 持仓交易
- 仅当用户提供持仓或授权调用持仓工具后填写真实数据。
- 无数据 → 整段写："未提供持仓数据，跳过（依据 SKILL.md 第 1 节约束）。"

## 7. 次日预案
条件化建议，**每条必含三要素**：
```
【预案】关注医药主线延续
- 触发条件：明日医药出现 ≥2 只 2 连板 且 昨日涨停板块转正。
- 失效条件：头雁（医药20cm）集体断板或跌超5%，或涨停数萎缩<50。
- 仓位上限：单主线 ≤ 30% 总仓。
```
可对多个场景各写一条（主线确认 / 反弹证伪 / 增量行情）。

## 8. 风险控制
- 风险红线（明确信号 → 动作，如"高位集体断板→管住手"）。
- 总仓位上限建议（如"分歧日总仓 ≤ 50%"）。
- 外部风险（贸易摩擦升级、外围暴跌）的应对。

## 9. 次日验证
列出明日回看本复盘对错的具体信号（2–5 个，可证伪）：
1. 医药是否出现 ≥2 只 2 连板？
2. 昨日涨停板块是否转正（>-1.57%→正）？
3. 成交额是否重回 2.2 万亿+ 且券商/半导体企稳？
4. 头雁（医药20cm）是否集体断板？
> 次日复盘时对照本清单自评命中率，校准判断。

## 10. 全天时间线（个性化版，报告尾部）

目标：让每天的时间线具有**独特辨识度**——读标签即知当日性格，读名场面即记当日高潮。五个子模块：

**① 今日标签**（3–6 个 hashtag，提炼当日独特性格，每日不同）
```
`#缩量修复日` `#医药蜂群` `#金健米业孤狼` `#科创逆风` `#断层雁阵` `#3900关口争夺战`
```

**② 日内形状**（ASCII 轨迹 + 形状命名 + 心理关口）
```
上证：3907(开) → 3925(高 09:46) → 3889(低 14:02) → 3903(收 +0.24%)
形状：高开冲高 → 午后翻绿探底 → 尾盘收回 = "勺型修复"
关键心理关口：3900 整数关（盘中两度失守、尾盘夺回）
```

**③ 日内轨迹**（data_minute 关键节点，故事线叙述）
> 上证分时：3907(开) → 3925(高,09:46) → 3889(低,14:02) → 3903(收,+0.24%)
> 创业板分时：3517(开) → 3531(高,09:46) → 3467(低,14:00) → 3495(收,+0.64%)
> 故事线：早盘医药一字潮点燃情绪 → 冲高即遇抛压 → 午后航天/半导体拖累翻绿 → 尾盘黄金/医药托底收回。

**④ 今日名场面**（当日最值得记住的一个瞬间，带场景叙事）
> 14:02 · 3900 关口争夺战：上证探至 3889，一度翻绿。恐慌盘涌出瞬间，紫金矿业逆势拉升 +4.55% 稳住阵脚……这一刻定义了今日"缩量修复而非崩塌"的基调。

**⑤ 时段节点表**（五列：时段/情绪/核心事件/暗流(推断)/数据来源）
| 时段 | 情绪 | 核心事件 | 暗流（推断） | 数据来源 |
|---|---|---|---|---|
| 盘前 | 多消息发酵 | 化工净利暴增229倍、SK海力士、中金三合一 | 消息面多但杂，无单一主线定调 | data_hot news |
| 竞价 | 偏热 | 沃森一字、紫金/医药/黄金高开；科创50 低开 | 科技与医药开盘即分化 | data_minute |
| 早盘 | 情绪高点 | 医药 20cm 涨停潮扩散；上证冲高 3925 | 蜂群广度强但无连板跟随，虚热信号 | data_minute/data_hot |
| 午盘 | 转冷 | 半导体/航天拖累；上证探 3889 翻绿 | 获利盘涌出 + 机构卖石药/恒逸 | data_minute/data_lhb |
| 尾盘 | 修复 | 上证/创业收回小红；紫金守 +4.55% | 收回靠避险托底，非增量抄底 | data_minute |
| 盘后 | 外围偏弱 | 美股低开；港股 +0.80%；黄金/原油走强 | 港股/黄金对冲美股偏弱 | data_quote/data_futures |

> **轨迹定性**（推断）：一句话点出当日形状本质 + 最真实的信号。

- 控制成本：每标的仅一次 `data_minute`，只取代表时点（竞价/开盘/方向确认/尾盘），不逐分钟细究。
- "今日标签"和"今日名场面"每日必须不同，禁止套用模板文案——它们是辨识度的核心。
